# PolarisMagic

Polaris 的自定义魔法能力组件。依赖同级 `PolarisCore`，并由 [Polaris](https://github.com/New-Cradle-of-Stella/Polaris) 聚合仓库作为 Git submodule 引用。

## 设计文档

- `doc/design/PolarisMagic-原型框架草案.md`：静态定义、code-behind 阶段回调与运行时边界。
- `doc/design/PolarisMagic-实现方案.md`：运行时实现与兼容方案。
- `PolarisMagic-落地计划.md`：确定的工程结构、公开契约与验收项。
